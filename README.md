# 🏥 Système de Gestion des Dossiers Médicaux

Application de bureau Java Swing pour la gestion complète d'un hôpital ou cabinet médical.

## ✨ Fonctionnalités

- **👥 Gestion des patients** : Ajout, modification, suppression et recherche de patients
- **👨‍⚕️ Gestion des médecins** : CRUD complet des médecins avec spécialités
- **📋 Gestion des consultations** : Enregistrement des consultations avec motifs, diagnostics et traitements
- **💊 Gestion des médicaments** : Stock, prix unitaire et prescriptions
- **📊 Tableau de bord** : Graphiques interactifs (consultations par mois, répartition mutuelle)
- **📑 Rapports PDF** : Export de rapports (patients, médecins, consultations, global)
- **💰 Facturation** : Génération et gestion des factures
